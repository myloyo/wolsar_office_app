## Ограничения среды
- Docker CLI доступен, Docker Engine не запущен. Compose и Dockerfile подготовлены, запуск PostgreSQL и сборка контейнеров не проверены.
- Установка Python-зависимостей в новое окружение прерывалась из-за сертификатов/тайм-аутов при скачивании с files.pythonhosted.org. Для тестов и локального сервера использовано существующее окружение с подходящими версиями; другие проекты не изменялись. Проверенные версии записаны в requirements.lock и requirements-dev.lock.
- Из-за прав на системный каталог временных файлов pytest запускался с `--basetemp=.pytest-tmp` из backend. Каталог исключён из Git.
- Локально Node.js 20.18; инструменты рекомендуют 20.19+. TypeScript, lint, тесты и сборка выполнились, но в Docker/CI выбран Node.js 22.
- PWA-установка, service worker в production, реальные уведомления и реальные внешние интеграции не проверены.
- Production-сборка предупреждает о большом JavaScript-пакете. Разделение загрузки по маршрутам — следующий шаг оптимизации.

# Текущая матрица доступа

Предложение от 5 ноября 2026; требуется утверждение владельцем. Сервер проверяет объект и действие, демо не включается в production.

| Область | Чтение | Изменение |
| --- | --- | --- |
| Пользователи, роли, приглашения, комнаты | Администратор | Администратор; нельзя отключить себя или последнего администратора |
| Общие события | Вошедшие пользователи | Офис и администратор |
| Отделение: проекты, лента, файлы, календарь | Члены отделения и администратор | Офис своего отделения и администратор |
| Служение: проекты, лента, файлы, календарь | Члены служения и администратор | Назначенный лидер этого служения и администратор |
| Задачи | Участники, администратор; офис своего отделения | Условия: постановщик/администратор; выполнение: также исполнитель/соисполнитель |
| Комментарий | Читатели задачи | Создать: участники выполнения; исправить/удалить/восстановить: автор/администратор |
| Недельный план | Владелец и администратор | Владелец текущей открытой недели |
| Цели и шаблоны | Авторизованные по соответствующим API | Администратор |
| Приоритеты | Свои отделения и администратор | Офис своего отделения и администратор |
| Богослужения, назначения, МС и таймер | Вошедшие пользователи | Офис отделения Богослужения (ID 1), администратор |
| Молитвы | Свои заявки; очередь доступна офису Богослужения/Взаимодействия (ID 1/5) и администратору | Своя заявка; включение в собрание — уполномоченный офис/администратор |
| Запись на слот | Участники доступного события | Самозапись члена служения при наличии места; снять себя/запросить замену |
| Уведомления и сеансы | Только свои | Только свои |

Роли совмещаются. Лидерство служения привязано к конкретному членству. Удаление членства/отключение сотрудника освобождает будущие записи через запрос замены; изменение ролей отзывает сеансы. Идентификаторы отделений 1 и 5 — временное соглашение, перед пилотом надо заменить организационной настройкой. Изменение состава пользователей не переписывает историю задач.
